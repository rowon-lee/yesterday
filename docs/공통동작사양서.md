# 공통 동작 사양서 — 맞는 동작 7개

모든 캐릭터가 함께 쓰는 동작은 맞는 동작 7개뿐이다. 맞는 반응이 같아야 상대 상태를 한눈에 읽을 수 있기 때문이다. 뼈대가 같으니 장식(머리, 옷자락, 무기)은 각 캐릭터의 것이 관절을 따라 그대로 붙는다.

| 순서 | 동작 | 프레임 | 기본 길이 | 늘어나는 프레임 |
| --- | --- | --- | --- | --- |
| 1 | 약하게 맞음 | 12 | 20틱 | 5 |
| 2 | 세게 맞음 | 14 | 32틱 | 6 |
| 3 | 가드 크러시 | 12 | 44틱 | 7 |
| 4 | 공중에서 맞음 | 12 | 16틱 + 반복(8틱) | 10~12 반복 |
| 5 | 다운 | 14 | 33틱 + 누운 채 대기 | 14 유지 |
| 6 | 기상 | 12 | 24틱 | 없음 |
| 7 | 낙법 | 12 | 18틱 | 없음 |

만드는 순서도 이 표 순서대로 한다. 한 번에 하나씩 만들고, 승인을 받은 뒤 다음으로 넘어간다(CLAUDE.md "동작 승인 절차").

---

## 공통 규칙

- **12~14프레임 규칙을 지킨다.** 맞는 시간(경직)은 공격마다 다르다. 그래서 프레임 수는 고정하고, 표의 "늘어나는 프레임"의 표시 틱(`dur`)만 늘려서 길이를 맞춘다. 예: 약하게 맞음의 경직이 26틱이면 5번 프레임 `dur`에 6틱을 더한다.
- **방향**: 표는 오른쪽을 보는 캐릭터가 앞(오른쪽)에서 맞는 기준이다. 뒤에서 맞으면 같은 동작을 그대로 재생하고, sim에서 맞은 쪽을 향해 몸을 돌린다.
- **밀려나는 거리는 sim이 정한다.** 동작은 제자리에서 몸만 반응한다. 엉덩이 이동은 몸이 젖혀지는 정도이고, 실제로 밀려나는 거리는 공격 데이터의 넉백 값을 쓴다.
- **판정**: 별도 표시가 없으면 맞는 판정(피격 상자)은 켜져 있다. 무적 구간은 동작별 표에 적는다.
- **연출**: 맞는 순간의 히트스톱, 하얀 번쩍임, Impact 이펙트는 게임기획서 "연출 규칙"대로 붙는다. 이 문서는 몸의 움직임만 정한다.
- **자세 표기**: 기준 자세(대기, STANCE)에서 얼마나 바뀌는지로 적는다. 엉덩이 이동은 px(오른쪽·위가 +), 몸통과 머리 기울기는 도(앞으로 숙임이 +, 뒤로 젖힘이 −)다. 팔다리 목표는 말로 적는다. 정확한 값은 Claude Code가 자세 데이터로 옮기면서 맞춘다.
- **키프레임 보간**: 굵게 표시한 프레임이 키프레임이고, 나머지는 3차 에르미트 보간으로 채운다. `stop`이라고 적힌 키는 그 자리에서 멈췄다 출발한다.

## 1. 약하게 맞음

평타 1~3타 같은 가벼운 공격에 맞았을 때. 상체만 짧게 젖혀졌다가 바로 돌아온다. 다음 공격에 이어 맞을 수 있게 빨리 회복한다.

- 확인할 것: 처음 2프레임 안에 "맞았다"가 읽히는가. 머리가 몸통보다 먼저 젖혀지는가.

## 2. 세게 맞음

평타 4타, 차지, 스킬처럼 강한 공격에 맞았을 때. 몸이 반으로 접히듯 크게 흔들리고 한 발 뒤로 휘청인다.

## 3. 가드 크러시

방어 내구도가 다 닳아 방어가 깨졌을 때. 막고 있던 팔이 위로 튕겨 벌어지고, 몸이 뒤로 비틀거리며 잠깐 무방비가 된다. 상대가 확실히 반격할 수 있는 시간이다.

| 프레임 | dur | 자세 |
| --- | --- | --- |
| **1** | 1 | 방어 자세에서 시작(두 팔을 얼굴 앞에 모음, 무릎 굽힘) |
| 2 | 1 | 팔이 바깥으로 튕기기 시작 |
| **3** | 2 | 두 팔이 위·뒤로 크게 벌어짐(손이 머리보다 위). 몸통 −15°, 머리 −20° |
| 4 | 2 | |
| 5 | 3 | 엉덩이 −4px, 뒷발 한 걸음 뒤로 |
| 6 | 3 | |
| **7** `stop` | 8 | 무방비. 몸통 −22°, 머리가 힘없이 뒤로 −30°, 팔은 벌어진 채 늘어지기 시작, 무릎이 흔들림. **경직이 길면 이 프레임이 늘어남** |
| 8 | 4 | 몸통이 앞으로 흔들려 −10° |
| 9 | 5 | 고개를 털 듯 머리 좌우로 한 번 흔들림 |
| 10 | 5 | 팔을 다시 앞으로 모으기 시작 |

- 합계 44틱. 이 중 앞 30틱 정도는 아무것도 할 수 없는 무방비 구간이다(정확한 값은 sim 밸런스에서).
- 이펙트: 방어막이 깨지는 파편(Shield 응용), 짧은 화면 흔들림.
- 확인할 것: 3번에서 "방어가 깨졌다"가 크게 읽히는가. 7번에서 무방비라는 게 보이는가.

## 4. 공중에서 맞음

공중에 뜬 상태에서 맞았을 때(띄우기 이후 공중 콤보 등). 몸이 뒤로 젖혀지며 돌고, 팔다리가 힘없이 따라온다. 공중에 있는 동안은 마지막 몇 프레임을 반복한다.

| 프레임 | dur | 자세 |
| --- | --- | --- |
| **1** | 1 | 충격. 몸통 −20°, 머리 −25°, 다리가 앞으로 들림 |
| 2 | 1 | |
| 3 | 2 | |
| **4** | 2 | 몸 전체가 뒤로 기울며 회전. 몸통 −50° |
| 5 | 2 | |
| 6 | 2 | 몸통 −70°, 팔은 위로 끌려 올라감, 다리는 굽혀짐 |
| 7 | 2 | |
| **8** | 2 | 몸통 −80°(거의 누운 채 공중). 팔다리 느슨하게 벌어짐 |
| 9 | 2 | |
| **10** | 2 | 공중 유지 자세 1: 팔다리가 천천히 흔들림 |
| 11 | 3 | 공중 유지 자세 2 |
| **12** | 3 | 공중 유지 자세 3 → 10번으로 돌아가 반복 |

- 1~9번(16틱)은 한 번, 10~12번(8틱)은 떨어지는 동안 반복한다. 공중에서 다시 맞으면 1번부터 다시 재생한다.
- 낙법이 가능해지는 순간(콤보 보정에서 정함) 몸이 한 번 하얗게 깜빡여 알린다(렌더 전용).
- 바닥에 닿으면 다운으로 넘어간다.
- 확인할 것: 공중 콤보 중 연달아 맞을 때 뚝뚝 끊기지 않는가. 회전 방향이 일정한가.

## 5. 다운

공중에서 떨어져 바닥에 닿았을 때, 또는 쓸기에 맞았을 때. 바닥에 부딪혀 한 번 튀었다가 눕는다.

| 프레임 | dur | 자세 |
| --- | --- | --- |
| **1** | 1 | 바닥 충돌. 등이 바닥에 닿음(누운 자세, 머리가 뒤쪽). 팔다리가 충격으로 들림 |
| 2 | 1 | |
| **3** | 2 | 튕김. 몸 전체가 4px 떠오름, 몸통이 살짝 꺾임 |
| 4 | 2 | |
| 5 | 2 | |
| **6** | 2 | 다시 바닥. 먼지 이펙트 |
| 7 | 2 | |
| 8 | 2 | 팔다리가 바닥에 늘어짐 |
| 9 | 3 | |
| 10 | 3 | |
| 11 | 3 | 가슴이 한 번 크게 들썩임(숨) |
| 12 | 3 | |
| 13 | 3 | |
| **14** | 3 | 완전히 누운 자세. **누운 채 대기는 이 프레임을 유지** |

- 합계 33틱 + 누운 채 대기(기본 30틱, sim에서 정함). 대기가 끝나면 기상으로 넘어간다.
- 무적: 1번부터 기상이 끝날 때까지 맞는 판정 없음(누운 상대 추가 타격 없음, 제안).
- 쓸기에 맞아 넘어질 때도 따로 동작을 만들지 않고 이 동작을 쓴다(공통 동작 수를 늘리지 않기 위해).
- 확인할 것: 튕김(3)이 무게감 있게 보이는가. 누운 자세에서 머리 방향이 일정한가.

## 6. 기상

다운에서 일어날 때. 팔로 바닥을 짚고 상체를 일으킨 뒤 무릎을 세워 선다.

| 프레임 | dur | 자세 |
| --- | --- | --- |
| **1** | 2 | 누운 자세에서 뒤쪽 팔이 바닥을 짚음 |
| 2 | 2 | |
| **3** | 2 | 상체를 일으킴(몸통 −45°), 머리가 앞으로 |
| 4 | 2 | |
| **5** | 2 | 앉은 자세. 한쪽 무릎을 세움 |
| 6 | 2 | |
| **7** | 2 | 짚은 손을 밀고 한쪽 무릎을 꿇은 자세 |
| 8 | 2 | |
| **9** | 2 | 일어서는 중. 엉덩이 높이 −6px, 몸통 +15° |
| 10 | 2 | |
| 11 | 2 | 팔이 기준 자세로 |
| **12** | 2 | 기준 자세로 복귀 |

- 합계 24틱.
- 무적: 1~10번(기상 무적). 11~12번부터 다시 맞는다.
- 나중에 기상 방향(앞으로 구르기·뒤로 구르기)을 넣고 싶으면 그때 공통 동작을 추가한다. 지금은 제자리 기상 하나다.
- 확인할 것: 짚고 → 앉고 → 무릎 → 선다, 네 단계가 자연스럽게 이어지는가.

## 7. 낙법

공중에서 맞고 있을 때 낙법이 가능한 순간 점프를 누르면 몸을 웅크려 한 바퀴 돌며 빠져나온다.

| 프레임 | dur | 자세 |
| --- | --- | --- |
| **1** | 1 | 공중에서 맞는 자세에서 시작. 무릎을 가슴으로 당김 |
| 2 | 1 | 몸을 둥글게 웅크림(팔이 무릎을 감쌈) |
| **3** | 1 | 뒤로 회전 시작, 90° |
| 4 | 1 | 180° |
| 5 | 2 | 270° |
| **6** | 2 | 360°. 웅크림이 풀리기 시작 |
| 7 | 2 | 팔다리를 펼침 |
| 8 | 2 | |
| **9** | 2 | 공중 균형 자세(점프 낙하 자세와 같음) |
| 10 | 1 | |
| 11 | 2 | |
| **12** | 1 | 낙하 동작으로 넘어감 |

- 합계 18틱.
- 무적: 1~8번. 회전하는 동안 잡히지 않는다.
- 이펙트: 회전 궤적을 따라 흰 잔상 짧게(Dash & Blink 응용).
- 끝나면 공중 이동이 가능한 낙하 상태가 된다. 땅에 닿으면 착지 동작.
- 확인할 것: 공중에서 맞는 동작(4번 동작)과 확실히 달라 보이는가. "빠져나왔다"가 읽히는가.
