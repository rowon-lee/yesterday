# 캐릭터 레퍼런스

사용자가 채팅에 올린 캐릭터 일러스트 (2026-11-02). 스틱맨 표식·대표 색을 이 그림에 맞춰 다시 깎았다 (`src/anim/decor/*`). 게임에 넣지 않는다.

- `에드워드_일러스트_2026-11-02.webp`: 왼쪽은 와인포드 가주(붉은 롱코트·검은 조끼와 바지·흰 머리), 오른쪽은 제9대 이능력범죄대응국장(흰 롱코트·금빛 견장·검은 제복·워 해머). 게임에서는 1P가 가주, 2P가 국장 색이다.
- `오스카_일러스트_2026-11-02.webp`: 곱슬 금발, 발목까지 오는 검은 롱코트와 검은 쓰리피스 정장, 검은 장갑, 긴 카타나.
- `백은우_일러스트_2026-11-02.png`: 잿빛 머리(긴 앞머리·낮게 묶은 꽁지머리), 검은 셔츠.
