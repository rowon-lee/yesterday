# [가제] YESTERDAY 스틱 액션 — 게임 기획서

Oct 30, 2026 · @주호영

## 개요

YESTERDAY 세계관의 히어로·빌런이 되어 싸우는 도트 액션 게임이다. 블리치 vs 나루토처럼 버튼은 적고 콤보와 기술이 화려한 전투를, 두 가지 모드로 즐긴다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 옆에서 보는 2D 도트 액션 (블리치 vs 나루토식 전투) |
| 세계관 | YESTERDAY · 2140년 뉴 샌디에이고, 세상이 망한 뒤 1960년대 미국 도시풍으로 새로 지은 디스토피아 도시 |
| 모드 | 대련(1:1 온라인 대전), 마수 토벌(3인 편성 로그라이트) |
| 그림 | 코드로 그린 굵은 선 스틱맨 + 장식 + 픽셀 이펙트 |
| 규격 | 화면 480×270, 캐릭터 칸 64×64, 동작당 12~14프레임, 1초 60틱 |
| 처음 인원 | 4명 — 라이덴, 백은우, 에드워드, 오스카 (캐릭터 기획서 참고) |
| 제작 | 기획은 이 프로젝트, 디자인과 구현은 전부 Claude Code |

이전 기획인 YESTERDAY 스컬류 로그라이트는 이 게임의 마수 토벌 모드로 합쳤다. 앞서 만든 정통 대전 기획서는 이 문서로 대체한다.

## 확정 사항

- 전투는 블리치 vs 나루토식. 버튼은 공격, 점프, 대시, 기술 A, 기술 B, 필살 6개다.
- 공중 콤보를 넣는다.
- 대련은 1:1 단일 캐릭터다. 교대는 없다.
- 마수 토벌은 캐릭터 3명을 편성하고 판 도중에 바꿔 가며 싸운다.
- 평타는 캐릭터마다 다르다.
- 최종 그림은 코드로 그린 굵은 선 스틱맨 + 장식 + 이펙트다. 그림 시트 제작은 하지 않는다.
- 이펙트는 Sprite Fusion 픽셀 아트 VFX 수준을 기준으로 삼는다.
- 스프라이트는 64×64, 동작당 12~14프레임, 움직임은 완전히 부드럽게.
- 기획은 이 프로젝트에서, 디자인과 구현은 Claude Code에서 한다.
- 시스템을 먼저 기본 스틱맨으로 완성하고 캐릭터를 얹는다. 동작은 하나마다 직접 확인하고 승인한다.
- 마수 토벌은 결재의 달인과 연동하지 않고, 판이 끝나면 예산만 정산한다. 히어로와 빌런을 섞어 편성하고, 상성이 있다.

## 조작과 전투 시스템

버튼 6개와 방향만 쓴다. 커맨드 입력(↓↘→ 같은 방향 조합)은 없다. 휴대폰 터치로도 같은 조작을 할 수 있어야 한다.

| 입력 | 지상 | 공중 |
| --- | --- | --- |
| ← → | 걷기 (앞·뒤) | 조금 움직임 |
| ↓ 누르고 있기 | 방어 | — |
| 공격 | 연타하면 캐릭터별 4타 콤보 | 연타하면 3타 콤보 |
| ↑ + 공격 | 띄우기 | — |
| ↓ + 공격 | 쓸기 (맞으면 다운) | 내려찍기 |
| 점프 | 점프 | 2단 점프 (1회) |
| ↓ + 점프 (발판 위) | 발판에서 내려오기 | — |
| 대시 | 짧은 순간이동식 돌진 | 공중 대시 (1회) |
| 기술 A · 기술 B | 캐릭터 고유기, 기력 1칸 | 공중에서도 쓸 수 있는지는 캐릭터별로 정함 |
| 필살 | 기력 3칸을 모두 써서 쓰는 큰 기술 | — |

**방어와 가드 크러시**: ↓를 누르고 있으면 앞에서 오는 공격을 모두 막는다(상단·하단 구분 없음, 앉기 없음). 잡기는 없다. 대신 막을 때마다 방어 내구도가 줄고, 다 닳으면 방어가 깨져 잠깐 무방비가 된다. 내구도는 막지 않는 동안 다시 찬다.

**기력**: 3칸. 때리거나 맞을 때만 차고, 따로 모으는 버튼은 없다. 대시는 기력을 쓰지 않는다(제안).

**낙법**: 공중에서 맞고 있을 때 점프를 누르면 몸을 돌려 빠져나온다. 콤보 중 일정 횟수 이상 맞으면 낙법이 가능해져서, 공중 콤보가 무한히 이어지지 않는다.

**콤보 보정**: 한 콤보에서 많이 맞을수록 피해가 줄고(최소 35%), 공중에서 맞으면 조금씩 더 빨리 떨어진다.

**벽 기동과 구조물**

구간마다 딛고 오를 구조물이 2~3개 있고, 높이는 서로 다르다.

- 구조물: 시타델 정문 기둥탑, 등대, 비상계단, 옥상 급수탑, 극장 차양, 뒤집힌 노면전차, 잔해 더미. 맵 양 끝 벽(서쪽 컨테이너 더미, 동쪽 공원 철책)도 벽 기동에 쓴다.
- 뒤쪽 건물 정면은 딛을 수 없다.
- 구조물 윗면은 서 있는 발판이다. 아래에서 뛰면 통과하고, ↓+점프로 내려온다. 대련과 마수 토벌 모두 같다.
- 구조물 옆면은 벽 기동에 쓰는 벽이다. 길을 막지는 않는다(구조물은 싸우는 줄보다 뒤에 있어 캐릭터가 그 앞을 지나간다).

버튼은 늘리지 않는다.

| 동작 | 입력 | 하는 일 |
| --- | --- | --- |
| 벽 붙기 | 공중에서 벽 쪽 방향을 누른 채 벽에 닿음 | 벽을 등지고 붙어 천천히 미끄러진다. 솟는 중에 닿으면 솟는 힘이 다할 때까지 벽을 타고 오른다. 벽 쪽 방향을 놓거나 ↓를 누르면 떨어진다 |
| 벽 점프 | 붙은 채 점프 | 반대쪽으로 튕겨 오른다(어느 방향을 누르든). 벽을 디뎌 생긴 2단 점프·공중 대시는 남고, 직후 잠깐 공중 좌우 조작이 듣지 않는다 |
| 벽 달리기 | 벽 쪽으로 대시 | 약 1.5층(135px) 달려 올라간다. 꼭대기가 그 안이면 윗면에 올라선다 |
| 벽 박차기 공격 | 붙은 채 공격 | 대각선으로 날아가며 공격한다 |
| 벽 낙법 | 벽꽝 당하는 순간 점프 | 박히지 않고 튕겨 나간다 |

- 벽을 딛으면 2단 점프와 공중 대시가 한 번씩 다시 생긴다. 같은 벽은 연속 두 번까지만 딛는다.
- 구조물에도 내구도가 있다. 무너지면 벽과 발판이 사라지고, 위에 있던 캐릭터는 떨어진다.
- 구조물 위치·내구도·무너진 시점은 sim 상태다(결정론).
- 벽 기동 동작 5개는 캐릭터 전용 동작이다(아래 '캐릭터 구성'). 지금은 기본 스틱맨의 기본형을 쓴다.

**코드 구조 원칙**: 1초 60틱 고정. 모든 기술은 발동·지속·후딜레이를 틱 수로 정한다. 게임 계산에 무작위 값을 쓰지 않아, 같은 입력이면 같은 결과가 나오게 한다(온라인 대전에 필요).

## 공중 콤보 흐름

[embedded content: 공중 콤보 흐름 · 띄우기부터 기상까지]

공중 콤보의 기본 흐름이다. 캐릭터마다 평타가 달라서 어느 타에서 띄우고 어떻게 따라가는지는 캐릭터별로 다르다. 맞는 쪽은 많이 맞으면 낙법으로 빠져나갈 수 있어서, 콤보가 무한히 이어지지 않는다.

## 모드

두 모드는 같은 전투 시스템과 같은 캐릭터를 쓴다. 다른 것은 상대와 편성뿐이다.

|  | 대련 | 마수 토벌 |
| --- | --- | --- |
| 상대 | 다른 플레이어 (온라인), 연습용 CPU | 마수 (소형 무리 → 중형 → 대형 보스) |
| 편성 | 1명 | 3명, 판 도중 교대 |
| 승리 | 3판 2선승, 라운드 60초 | 구역을 돌파하고 마지막 보스 토벌 |
| 성장 | 없음 (실력 슸부) | 판 안에서 보상으로 강화, 판이 끝나면 예산 정산 |
| 규모 | 한 판 3~5분 | 전체 1시간 이상 |

**대련**: 방 코드로 두 사람이 만나 1:1로 붙는다. 입력만 주고받는 방식(딜레이 방식)으로 먼저 만들고, 느리면 롤백으로 바꾼다.

**마수 토벌**: 스컬류 로그라이트다. 히어로와 빌런 3명을 섞어 편성하고 출동한다. 현장에는 1명만 나가 있고, 나머지 둘과 바꿔 가며 싸운다. 편성 조합에는 상성이 있다. 민간 피해 같은 별도 리스크는 없다. 자세한 구조(구역 수, 보상, 예산 쓰임새)는 마수 토벌 기획서를 따로 쓴다.

## 무대와 파괴 (제안)

무대는 2140년 뉴 샌디에이고 도심이다. 세상이 망한 뒤 1960년대 미국 도시풍으로 새로 지은 디스토피아 도시다. 벽돌 건물, 철제 비상계단, 다이너, 극장, 노면전차, 1960년대 자동차, 가스 네온 간판과 전광판이 거리를 채우고, 그 사이로 선전 포스터, 검문소, 감시탑 서치라이트, 공장 매연이 디스토피아 분위기를 만든다. 네온 전광판은 있지만 떠다니는 차나 로봇 같은 미래 기술은 없다. 기본은 비 오는 밤이다(아래 '비주얼'의 '분위기와 조명'). 맵은 화면보다 훨씬 넓고, 싸우는 동안 도시가 부서진다. 부수는 맛은 연출과 재미를 위한 것이고, 부순다고 벌점을 받지는 않는다.

**맵 크기**

- 대련 맵은 3,200×540px이다(화면 480×270의 가로 약 6.7배, 세로 2배). 카메라가 두 캐릭터를 가로·세로로 따라가고, 두 사람은 화면 한 칸 안에서 벗어날 수 없다. 띄우기·공중 콤보 때는 카메라가 위로 부드럽게 따라 올라가 위층과 하늘이 보인다.
- 맵을 구간으로 나눠 이동할 때마다 풍경이 바뀐다. 구간과 배경은 아래 '대련 무대: 시타델 1구역'을 따른다.
- 높이는 세 층이다: 지상, 중층(차양·비상계단·계단참), 옥상(지붕·테라스).
  - 발판은 한 방향이다. 위에서 내려올 때만 서고, 아래에서는 뚫고 올라간다.
  - 발판 위에서 ↓+점프로 내려온다. 발판 끝을 넘어 걸어가면 떨어진다.
  - 부서지는 건물에 붙은 발판(차양·비상계단·지붕)은 그 자리가 무너지면 사라진다.
- 마수 토벌은 구역마다 더 길게 이어진 맵을 오른쪽으로 돌파한다.

**대련 무대: 시타델 1구역**

시타델은 뉴 샌디에이고 제1구역 한가운데 있는 히어로 총국 본부다. 대련은 성벽 안 도시 한 겹만 쓴다. 시작 위치는 광장 가운데 분수 양쪽(1,480과 1,720)이다.

| 구간 | 범위 | 풍경 |
| --- | --- | --- |
| 해안 부두 | 0~400 | 방파제, 철제 난간, 등대 서치라이트. 서쪽 끝은 컨테이너 더미 벽 |
| 극장·다이너 거리 | 400~1,000 | 극장 차양, 다이너, 노면전차 선로, 주차된 자동차. 차양은 올라설 수 있는 발판 |
| 시타델 광장 | 1,000~2,200 | 정문 계단, 분수, 히어로 동상, 시타델 본관 |
| 비상계단 아파트 | 2,200~2,800 | 벽돌 아파트, 층층이 발판이 되는 철제 비상계단, 옥상 전광판 |
| 시타델 공원 | 2,800~3,200 | 나무, 벤치, 가로등. 어둡고 조용하게. 동쪽 끝은 철책 벽 |

- 시타델 본관은 화면보다 훨씬 높은 1960년대 마천루다(유리 커튼월, 기둥이 늘어선 로비 기단부). 본관은 아래 '시타델 붕괴'를 따른다.
  - 정문 계단과 계단참(중층 발판), 유리 정문과 캐노피
  - 정문 양옆 콘크리트 기둥: 싸우는 줄 위로 나와 있어서 7-D에서 딛고 오를 곳
  - 기둥 중간 캔틸레버 테라스와 꼭대기(옥상 발판, 항공 경고등)
  - 정면 대형 간판, 옥상 서치라이트
- 다른 건물도 화면보다 높다(3~6층, 높이 200~360px).
- 배경은 6겹이다. 멀수록 느리게 움직인다 (2.5D 화면에서는 겹마다 그 속도에 맞는 깊이에 놓는다. 아래 '비주얼').
  1. 하늘과 바다·등대 불빛
  2. 1구역 마천루 실루엣
  3. 시타델 탑 윗부분(층층이 들어간 마천루 꼭대기, 안테나와 경고등)과 서치라이트
  4. 중간 건물
  5. 싸우는 거리
  6. 앞겹: 카메라 앞을 스치는 가로등 기둥, 전선, 깃대와 깃발. 아주 어두운 실루엣이고, 화면 가운데로 오면 디더링으로 사라져 가장자리에서만 보인다.
- 먼 겹일수록 어둡고 색이 빠지고 안개에 묻힌다. 흐림(블러) 대신 매연 색 디더링과 거리 안개로 덮는다.
- 도시가 움직인다(모두 렌더 전용, 게임 계산에 넣지 않는다).
  - 노면전차가 가끔 싸우는 거리 바로 뒤(건물 앞 차선)로 지나간다. 판정은 없다.
  - 서치라이트가 하늘을 쓴다.
  - 분수가 솟는다.
  - 멀리 실루엣 행인이 싸움을 피해 도망간다.
- 광장 동쪽 입구에 검문소 초소와 바리케이드가 있고, 먼 겹에는 공장 굴뚝 매연이 오른다(둘 다 부서지지 않는다).
- 부서지는 물건(1960년대 자동차·가로등·쇼윈도·네온 간판·신문 가판대·소화전)은 구간에 맞게 놓는다.
- 분위기와 조명은 '비주얼'의 '분위기와 조명'을 따른다: 비 오는 밤, 네온과 가로등 빛, 젖은 바닥 반사.

**부서지는 것**

| 대상 | 부서지는 모습 | 쓸 이펙트 |
| --- | --- | --- |

| 상점 간판·차양 | 찢어짐 → 떨어짐 | Impact |
| 쇼윈도 유리 | 금 → 산산조각 | Impact (파편) |
| 신문 가판대·우체통·나무 통 | 찌그러짐 → 날아감 | Impact, 먼지 |
| 소화전 | 부러지면 물기둥이 솟음 | Rain의 물보라 응용 |
| 벽돌 벽·바닥 | 금, 벽돌이 무너짐, 그을린 자국, 잔해가 남음 | Explosion, 먼지 |

- 부서지는 물건은 내구도가 있고 3단계(멀쩡 → 망가짐 → 파괴)로 모습이 바뀐다. 모두 코드로 그린다.
- 상대를 세게 날려 물건에 부딪히면 한 번에 부서지고, 부딪힌 쪽은 추가 피해를 입는다.
- 잔해, 그을린 자국, 깨진 유리는 라운드가 넘어가도 남는다(아래 '건물 파괴'와 같다). 싸울수록 도시가 엉망이 된다.
- 부서진 물건은 판정에 영향을 주지 않는 장식이다(온라인 동기화를 단순하게 하려고). 단, 어느 물건이 언제 부서졌는지는 게임 계산에 포함해 양쪽 화면이 같게 보이게 한다.
  - 예외: 구조물과 큰 물건. 무너지면 그 발판과 벽이 사라지고, 뒤집힌 노면전차·떨어진 간판·등대 밑동·잔해 더미는 새 발판과 벽이 된다(위 '벽 기동과 구조물').
- **큰 물건**(노면전차, 급수탑, 등대, 시타델 간판)은 평타·기술로는 망가짐까지만 간다. 필살기가 닿거나 벽꽝(벽 쪽으로 날린 상대가 부딪힘)이면 크게 무너지고, Explosion·먼지·화면 흔들림이 따른다.
  - 시타델 1구역 배치: 노면전차는 부두~극장 거리 선로를 지나가는 동안, 급수탑은 비상계단 아파트의 식료품점 지붕, 등대는 해안 부두, 간판은 시타델 본관 정면.
  - 부서진 시점(과 뒤집힌 전차의 자리)은 sim 상태, 쓰러지는 모습·물·불꽃·먼지는 렌더 전용이다.

**건물 파괴**

- 건물 정면을 16×16px 덩어리 격자로 나누고 덩어리마다 내구도. 근처의 강한 타격, 날아온 캐릭터, 폭발이 범위 안 덩어리를 깎음.
- 깎이면 금 → 구멍 → 뚫림 3단계. 뚫린 자리 뒤로 실내(벽지, 계단, 가구, 배관)가 보이게.
- 아래층이 많이 뚫리면 위가 무너짐: 위 덩어리가 잔해로 떨어지고 큰 먼지 구름, 화면 흔들림, 짧은 슬로모션.
- 캐릭터가 건물 쪽으로 세게 날아가면 정면에 박히는 벽꽝(건물이 패이고 튕겨 나옴, 추가 피해).
  - 건물 쪽으로 날리는 것은 기술마다 정한다('벽 쪽으로 날림' 표시). 기본 스틱맨은 4타·기술 B·필살. 표시 없는 강타는 옆으로 날아간다.
- 덩어리 상태와 무너진 시점은 sim 상태(결정론). 파편·먼지는 렌더 전용, 떨어지는 잔해는 판정 없음.
- 무너진 자리에는 잔해 더미가 쌓인다. 다 쌓이면 윗면이 발판, 양옆이 벽이 된다(위 '벽 기동과 구조물'). 더미는 한동안 불타고 그 뒤로는 잉걸불이 남아 어둠 속에서 더미를 비춘다(렌더 전용).
- 파괴는 라운드가 넘어가도 유지해서 3라운드쯤이면 거리가 폐허가 되게. 부서지는 물건(자동차·가로등·네온 간판 등)도 똑같이 유지한다.

**시타델 붕괴**

- 본관 내구도: 기둥탑과 정면 근처의 강한 타격, 벽꽝, 필살기가 깎는다.
- 금 → 유리가 깨지고 간판이 떨어짐 → 외벽이 갈라지고 불이 붙음, 3단계로 바뀐다.
- 3단계에서 필살기가 시타델에 닿으면 붕괴한다. 평타·기술만으로는 무너지지 않는다. 많이 때려서 금 가게 만든 뒤 필살기로 마무리하는 구조다.
- 붕괴 연출: 큰 화면 흔들림, 먼지 구름, 짧은 슬로모션, Explosion. 라운드는 끊기지 않고 이어지고, 떨어지는 잔해는 판정이 없다.
- 붕괴 후 광장은 잔해 언덕이다. 들쭉날쭉한 잔해가 새 발판과 벽이 되고(벽 기동 가능), 광장 네온은 꺼지고 불길과 서치라이트만 남는다.
- 붕괴는 다음 라운드까지 유지하고, 한 경기에 한 번만 일어난다. 다음 경기는 멀쩡한 시타델에서 시작한다.
- 내구도·붕괴 시점·잔해 지형은 sim 상태(결정론). 파편·먼지는 렌더 전용이다.

**벽꽝 → 다음 구역 (대련)**: 맵 끝 벽에 상대를 필살기나 강한 타격으로 박으면 벽이 무너지고, 두 사람이 옆 구역으로 넘어간다. 더 크게 부수는 맛을 주는 장치다.

**구역 후보**: 도심 대로(벽돌 건물과 노면전차 선로), 고가 철도 아래, 구역 경계 검문소, 항만 부두와 창고, 히어로 국 청사 앞 광장, 공장 지대, 밤의 옥상(급수탑과 감시탑). 구역마다 배경 이펙트(비, 안개, 불씨, 공장 매연)를 다르게 준다.

- 대표 색과 장식 (머리 모양, 코트·망토 자락, 무기, 들고 다니는 물건)

- 마수 토벌에서의 상성 (어떤 캐릭터와 같이 내면 좋은지)

## 비주얼

캐릭터는 단순하게, 화려함은 이펙트가 맡는다. 기준은 [Sprite Fusion 픽셀 아트 VFX](https://www.spritefusion.com/pixel-art-vfx) 수준이다.

**렌더 방식: 2.5D (기준: The Last Night)**

도트 그림을 3D 공간에 놓고 현대적인 조명을 입힌다. three.js(WebGL2)로 480×270 화면에 그린 뒤 정수배로 키운다. 게임 계산(sim)은 그대로 2D이고, 3D는 그림에만 쓴다.

1. 카메라: 긴 초점거리의 원근 카메라라서 거의 평면처럼 보인다. 픽셀 격자에 맞춰 정수 px로 움직이고, 남는 소수점은 확대 단계에서 화면을 밀어 도트가 지글거리지 않는다. 먼 것일수록 작고 느리게 움직여(시차) 깊이가 생긴다.
2. 형태와 텍스처: 건물·간판·차·가로등·비상계단은 단순한 3D 형태(상자 위주)에 코드로 그린 저해상도 도트 텍스처를 붙인다. 얼룩·녹·찢긴 포스터·빗물 자국으로 낡게, 형태는 일부러 조금씩 비뚤게, 같은 창문·벽돌을 되풀이하지 않는다. 먼 겹(하늘과 바다, 1구역 마천루, 시타델 탑, 중간 건물)은 도트 그림 판을 그 깊이에 세운다. 텍스처 한 칸이 화면 1px이 되게 깊이만큼 줄여 그린다.
3. 조명: 어둠에서 시작해 실제 광원으로 밝힌다. 환경광은 어둡고 차가운 남색. 네온·가로등·창문·서치라이트·불길·이펙트가 광원이 되어 벽과 바닥을 비춘다. 한 화면에 광원은 12개까지이고, 화면에 가장 크게 닿는 것부터 고른다. 빛 색은 주황·분홍·청록 위주.
4. 젖은 바닥: 화면 반사로 네온과 가로등이 바닥에 길게 비치고 빗물 물결로 흔들린다. 웅덩이와 소화전 물웅덩이가 더 세게 비친다.
5. 공기: 겹 사이 안개와 바닥 안개, 가로등·서치라이트·전조등 빛줄기, 하수구 증기, 불탄 차의 연기.
6. 비: 얇은 무채색 빗줄기 세 겹(먼 겹·싸우는 면 뒤·카메라 앞). 빛 안에서만 그 빛 색으로 반짝인다. 바닥과 발판에 물방울이 튄다.
7. 캐릭터: 스틱맨 시트를 싸우는 면에 판으로 세우고, 가까운 광원 색으로 테두리 빛을 입힌다. 이펙트는 캐릭터 바로 뒤·앞 판에 그린다.
8. 후처리: 빛 번짐(밝은 곳에만 약하게) → 깊이 기반 1px 외곽선 → 제한 팔레트로 색 줄이기 + 디더링. 매끈한 그라데이션이 남지 않는다.
9. 깊이 배치: 올라설 수 있는 곳(처마·차양·극장 차양·비상계단 발판·계단참·기둥 테라스·등대 둘레)은 얇은 판으로 싸우는 면까지 튀어나와 그 위에 선 캐릭터와 깊이가 맞는다. 올라설 수 없는 덩어리(건물 몸통·기둥·계단·분수)는 싸우는 면보다 뒤에 있어 캐릭터가 그 앞을 지나간다.
10. 파괴: 건물 정면이 금 → 구멍 → 뚫림으로 바뀌면 뚫린 자리 뒤로 실내(방·가게·객석)가 깊이를 두고 보인다. 무너진 칸은 정면·몸통·처마·차양·비상계단이 모두 사라져 뒤 겹이 보이고, 앞에 잔해 더미가 쌓인다. 네온 간판·가로등이 부서지면 그 빛도 꺼진다. 부서졌는지는 게임 계산에 있고, 빛·불길·연기·잔해는 그림에만 있다.
11. 성능: 휴대폰과 저사양 PC에서 1초 60프레임. 느리면 품질을 낮춘다 (광원 6개, 빗줄기 절반, 빛 번짐 끔). WebGL2가 없는 브라우저에는 안내 글을 띄운다.

**아트 규칙**

- 명도: 흑백으로 봐도 읽혀야 한다. 먼 겹은 어둡고 흐리게, 싸우는 줄은 또렷하게, 광원과 캐릭터 테두리가 가장 밝게. 벽과 바닥이 같은 밝기로 뭉치면 안 된다.
- 색 온도: 환경은 차갑게(남색·청록), 빛만 따뜻하게(주황·분홍). 벽돌도 어둠 속에서는 차가운 쪽으로. 배경은 녹슨 갈색·회색 벽돌·매연 낀 하늘처럼 채도를 낮추고, 밝은 색은 불빛과 캐릭터·이펙트에만 쓴다.
- 스케일: 캐릭터 키 52px 기준. 문 약 70px, 한 층 약 90px, 1960년대 자동차 길이 약 120px, 가로등 약 110px. 캐릭터가 문보다 크면 안 된다.
- 간판 위계: 구간마다 주인공 간판 하나만 가장 밝게 (극장·다이너 거리 PALACE, 비상계단 아파트 RADIO, 시타델 광장 CITADEL). 나머지는 어둡거나(DINER·GROCER), 깜빡이거나(HOTEL 세로 간판·LAUNDRY), 꺼진 것(BAKERY·HOTEL 가게 간판). 글자가 화면 가장자리에서 반쯤 잘려 보이지 않게 둔다.
- 앞겹: 카메라 앞 기둥·전선·깃발은 아주 어두운 실루엣으로, 화면 가장자리 쪽에 가끔만.
- 디테일: 철제 비상계단, 배관, 에어컨 실외기, 물탱크, 물웅덩이, 하수구 증기, 쓰레기봉투, 찢긴 선전 포스터. 불 켜진 창문은 일부만, 몇 개는 커튼 그림자나 TV 깜빡임.

**화면과 캐릭터 규격**

| 항목 | 규격 |
| --- | --- |
| 화면 | 480×270 (3D 렌더 타깃), 정수배 확대. 텍스처는 흐림 없이 디더링 |
| 캐릭터 칸 | 64×64, 발밑 기준점 (32, 61) |
| 캐릭터 키 | 약 52px |
| 선 굵기 | 팔다리 4px, 몸통 5px, 주변에 1px 어두운 외곽선 |
| 명암 | 빛을 받는 쪽을 한 단계 밝게. 뒷쪽 팔다리는 한 단계 어둡게 |
| 동작 | 동작당 12~14프레임. 뼈대와 관절 계산(IK)으로 포즈를 잡고, 키프레임 사이를 곡선으로 잇는다 |
| 색 | 캐릭터·지형·이펙트 그림은 같은 제한 팔레트와 디더링. 최종 화면은 후처리에서 제한 팔레트로 줄이고 디더링한다 |

굵은 선 스틱맨 위에 장식을 도형으로 얹어 인물을 구분한다. 장식은 뼈대에 붙어 있어서 어떤 동작에서도 모양이 흔들리지 않는다. 코트 자락이나 무기가 64×64 칸을 넘는 캐릭터는 칸을 96×96으로 키울지 따로 정한다.

이펙트는 파일 하나씩인 TypeScript 코드이고 MIT 라이선스다. Claude Code에 MCP로 연결해 가져오고, 색·크기·타이밍을 게임에 맞게 바꾼다. 목록에 없는 기술 이펙트는 같은 구조로 새로 만든다.

**연출 규칙**

- 맞는 순간 양쪽이 잠깐 멈춘다 (히트스톱, 약 7~12틱).
- 강한 타격은 화면 흔들림과 화면 번첍임을 같이 준다.
- 맞은 쪽은 몇 틱 동안 하얗게 번첍인다.
- 이펙트는 캐릭터 뒤와 앞 두 겹으로 나눠 그린다.
- 필살기는 화면을 어둡게 하고 기술 이름 컷인을 띄운 뒤 발동한다. 나중에는 AI로 만든 캐릭터별 컷씬 애니메이션으로 바꾼다. 캐릭터 대사는 넣지 않는다.
- 배경은 여러 겹을 깊이에 나눠 놓아 카메라와 다른 속도로 움직인다.

## 제작 방식

기획은 이 프로젝트에서 하고, 만드는 건 전부 Claude Code가 한다. 그림도 Claude Code가 코드로 그린다.

**Claude Code에 넘기는 문서**

1. 게임 기획서 (이 문서)
2. CLAUDE.md: 작업 규칙 (규격, 코드 구조 원칙, 승인 절차, 이펙트 라이브러리)
3. 동작 사양서: 동작마다 프레임 수, 자세 흐름, 판정 프레임, 이펙트
4. 작업 순서표: Claude Code에 하나씩 붙여 넣을 작업 지시

**동작 하나가 오가는 순서**

1. 여기서 동작 사양을 쓴다.
2. Claude Code가 그리고, 스프라이트 시트 PNG와 재생 화면을 만들어 직접 확인한다.
3. 직접 보고 고칠 점을 말하거나 승인한다.
4. 승인되면 다음 동작으로 넘어간다.

이 절차가 돌아가려면 Claude Code가 자기 결과물을 볼 수 있어야 한다. 그래서 가장 먼저 시트 PNG 출력, 대전 화면 캡처, CPU끼리 자동 대전 테스트를 만들게 한다.

**진행 단계**

1. **시스템**: 기본 스틱맨으로 전투 엔진, 공통 동작 7개(맞는 동작), 기본형 전용 동작 31개, 이펙트, 넓은 맵과 파괴, 벽 기동과 구조물을 만든다.
2. **대련 온라인**: 방 코드로 1:1 대전을 연결한다.
3. **캐릭터 4명**: 여기서 기획하고 Claude Code가 장식과 전용 동작을 만든다.
4. **마수 토벌**: 마수, 구역, 3인 편성과 교대, 보상, 예산을 만든다.
5. **조정과 배포**
