# 사운드 기획서

효과음과 음악을 모두 코드로 합성한다(Web Audio). 오디오 파일은 쓰지 않는다. 합성으로 도저히 안 되는 효과음만 사용자 승인을 받아 CC0 소리로 보충하고, 출처를 `docs/sound-credits.md`에 적는다.

---

## 0. 원칙

- **렌더 쪽 전용**: 소리는 그림처럼 렌더 쪽에서만 다룬다. `sim/`은 소리를 모른다. sim이 내는 사건(맞음, 가드, 가드 크러시, 착지, 파괴, 필살기 발동 등)을 받아 소리를 낸다. 결정론과 무관하다.
- **휴대폰**: 첫 터치나 키 입력 때 오디오를 켠다(브라우저 자동 재생 제한). 타이틀 화면에서 해결한다.
- **음량**: 전체·음악·효과음 세 가지를 설정에서 조절하고, 브라우저에 저장한다.
- **믹스**: 효과음이 음악보다 위. 마지막 단에 리미터를 둬서 여러 소리가 겹쳐도 찢어지지 않게 한다.
- **성능**: 동시 발음 수 상한(약 24). 같은 소리가 1틱 안에 여러 번 나면 하나로 합친다. 휴대폰에서 60프레임을 지킨다.
- **대사 없음**: 목소리, 아나운서, 외침은 넣지 않는다(CLAUDE.md).
- **베끼지 않기**: 기존 게임·영화 음악의 멜로디나 효과음을 따라 만들지 않는다.

## 1. 구조

```
src/audio/
  engine     믹서(음악·효과음·무대 버스), 리버브, 리미터, 음량 설정, 사건 → 소리 연결
  synth      부품: 오실레이터, FM, 노이즈, 필터, 엔벨로프, 디스토션, 피치 스윕
  sfx/       효과음 레시피(숫자 데이터)
  music/     곡 데이터(패턴, 화음, 악기 설정, 층)
tools/       npm run sound: 효과음 모음과 곡 스케치를 WAV로 뽑아 previews/sound/에 저장
```

- 효과음 하나 = 부품 몇 개를 겹친 레시피(예: 저음 쿵 + 노이즈 탁 + 짧은 꼬리).
- 같은 소리도 재생할 때마다 피치·길이를 조금씩 흔들어 기계 소리처럼 반복되지 않게 한다.

## 2. 효과음

### 2-1. 공통 타격

| 소리 | 방향 | 길이 |
| --- | --- | --- |
| 약하게 맞음 | 짧은 노이즈 "탁" + 낮은 클릭 | 40~80ms |
| 세게 맞음 | 낮은 "쿵" + 노이즈 폭발 + 짧은 꼬리 | 150~250ms |
| 가드 | 짧은 금속성 울림 | 80ms |
| 가드 크러시 | 유리 깨지는 소리 + 저음 | 300ms |
| 공중에서 맞음 | 세게 맞음보다 가볍고 높게 | 120ms |
| 다운·기상·낙법 | 젖은 바닥에 떨어지는 철퍽, 낙법은 짧은 바람 | — |

- **히트스톱과 맞물림**: 맞는 틱에 소리가 정확히 시작한다. 강타는 히트스톱 동안 다른 소리를 잠깐 낮춰 그 한 방이 들리게 한다.
- **콤보 변주**: 1→4타로 갈수록 저음이 깊어지고 꼬리가 길어진다.

### 2-2. 이동

발걸음(젖은 바닥 찰박), 대시(바람 휙), 점프, 착지(캐릭터 무게만큼), 벽 딛기, 공중 대시.

### 2-3. 캐릭터 표식 소리

| 캐릭터 | 표식 | 강타·기술 |
| --- | --- | --- |
| 라이덴 | 지지직 튀는 전기(높은 노이즈 + 빠른 떨림) | 전기 + 바닥을 때리는 저음, 4타는 전기가 앞으로 달리는 스윕 |
| 백은우 | 비단이 휘날리는 휘익(노이즈 스윕) + 끝에 가는 금속 "팅" | 연검 끝이 꺾일 때 "팅", 방어막이 깨질 때 유리 꽃잎 |
| 에드워드 | 낮고 긴 휘두름 바람 | 둔탁한 쿵 + 땅 울림, 염동력 장막은 낮은 "웅" |
| 오스카 | 칼 뽑는 "스릉" + 칼자루가 칼집에 닿는 딸깍 | 베기 직전 0.2초 모든 소리가 빠지고, 날카로운 "칭" 한 번 |

### 2-4. 연출

- **필살기 컷인**: 모든 소리가 확 내려가고 저음 한 방. 컷인이 끝나면 돌아온다.
- **임팩트 프레임**(동작연출지침서 14-9 A): 1~2틱 무음 → 폭발.
- **영역 전개형 필살기**(선의, 월령수류): 전개하는 동안 음악과 무대 소리에 필터를 걸어 먹먹하게 → 해제되면 열린다.

### 2-5. 무대와 파괴

- **늘 깔리는 소리**: 비(가까운·먼 겹 노이즈 2~3겹), 네온 웅웅거림(간판 가까이 가면 커짐), 빗물받이 물 떨어짐, 먼 공장 소음.
- **파괴**: 유리 깨짐, 벽돌 무너짐, 금속 휘어짐, 건물 붕괴 굉음 + 잔해 떨어지는 소리. 큰 붕괴는 저음이 길게.
- **간판이 부서지면** 그 간판의 웅웅거림도 끊긴다.

### 2-6. 화면

메뉴 이동, 결정, 취소, 라운드 시작(효과음만), 라운드 끝, KO.

## 3. 음악

### 3-1. 방향

**비 오는 밤의 느와르 신스.** 1960년대 느와르의 어두운 화성(단7·9화음, 반음 진행)을 신스로 연주한다.

- **악기**: FM 일렉트릭 피아노, 아날로그 패드, 서브 베이스, 노이즈로 만든 브러시·하이햇, 묵직한 킥, 신스 리드. 테이프 질감과 넓은 리버브.
- **피할 것**: 색소폰·트럼펫·어쿠스틱 피아노처럼 진짜 악기 흉내. 합성으로는 어색해진다. 신스답게 간다.
- **빠르기**: 대련곡 120~140, 하프타임 느낌. 타이틀·결과는 80~95.

### 3-2. 적응형 3층

대련곡은 층을 쌓고 빼며 싸움에 반응한다.

| 층 | 들어오는 때 | 구성 |
| --- | --- | --- |
| 기본 | 라운드 시작 전 | 패드, 베이스, 빗소리 |
| 전투 | FIGHT부터 | 드럼, 베이스 리듬 강화 |
| 고조 | 누군가 체력 30% 아래, 또는 마지막 라운드 | 리드 멜로디, 드럼 채움 |

- 필살기 컷인: 음악 필터를 닫고 낮췄다가 끝나면 원래대로.
- 라운드 끝: 화음 하나로 끊는다.

### 3-3. 곡 목록

| 순서 | 곡 | 길이 |
| --- | --- | --- |
| 1 | 대련 — 시타델 1구역 (3층) | 2~3분 반복 |
| 2 | 타이틀 | 1~2분 반복 |
| 3 | 결과 화면 | 20~30초 |
| 나중 | 캐릭터 테마 넷: 라이덴(빠른 단조 리프), 백은우(3박 왈츠), 에드워드(느리고 장엄한 저음), 오스카(5음계 리드) | 각 2분 |

## 4. 확인과 승인

- `npm run sound`가 효과음 모음과 곡 스케치를 WAV(모노 22kHz)로 뽑아 `previews/sound/`에 넣는다. 사용자는 휴대폰으로 GitHub에서 듣는다.
- PR에는 소리마다 번호를 붙인다. 사용자는 번호로 답한다("3 더 묵직하게").
- 배포된 게임에 소리 시험 화면(버튼을 누르면 해당 소리 재생, 음악 층 켜고 끄기)을 둔다.
- 곡은 처음에 **30초 스케치 2안**을 내고 하나를 고른 뒤 전체를 만든다.

## 5. 진행 순서

1. 엔진·부품·확인 도구 + 공통 타격음(2-1)
2. 캐릭터 표식 소리 넷(2-3) + 이동(2-2)
3. 무대·파괴(2-5) + 연출(2-4) + 화면(2-6)
4. 대련곡 스케치 2안 → 선택 → 전체 + 적응형 3층
5. 타이틀·결과 곡
6. 나중: 캐릭터 테마
