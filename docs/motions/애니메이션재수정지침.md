# 애니메이션 재수정 지침 (2차 리워크)

1차본(작업순서 3-0b~3-0e)은 12~14프레임 제한이 코드에 남아 있던 상태에서 만들었다. 제한을 풀고 판정을 공격 데이터로 분리한 지금(3-0a), 기존 동작을 CLAUDE.md "애니메이션 제작 원칙"에 맞춰 다시 깎는다.

**바꾸는 것은 그림뿐이다.** 판정, 캔슬 타이밍, 몸 이동(공격 데이터)과 이펙트는 그대로 둔다.

---

## 0. 먼저 점검표를 만든다

모든 동작(4명 × 33개 + 공통 7개 + 기본 스틱맨)마다 한 줄씩 `docs/motions/점검표.md`에 적는다.

| 동작 | 프레임 수 / 총 틱 | 일곱 요소가 든 프레임 번호 | 문제 신호 | 등급 |
| --- | --- | --- | --- | --- |

**문제 신호** (코드로 자동 검사하고, 걸린 항목을 적는다)

| 신호 | 검사 방법 |
| --- | --- |
| 복사로 길이 채움 | 관절 위치 차이가 1px 이하인 프레임이 2장 이상 이어짐(`stop` 키 제외) |
| 감기 없음 | 타격 프레임 앞 2~4프레임 안에 공격 반대 방향 움직임이 없음 |
| 지나치기 없음 | 타격 다음 프레임에 손·발·무기 끝이 더 나가지 않음 |
| 직선 궤적 | 손·발·무기 끝 경로가 거의 직선(호가 아님) |
| 일정한 간격 | 프레임 사이 이동 거리가 거의 같음(빨라지고 느려지는 차이가 없음) |
| 몸통 고정 | 공격 중 어깨·엉덩이 이동이 4px 미만 |
| 2차 동작 없음 | 머리카락·옷자락·무기 끝이 몸과 같은 프레임에 같이 멈춤 |
| 실루엣 겹침 | 대기와 타격 프레임의 단색 실루엣이 80% 이상 겹침 |
| 12~14에 눌림 | 3-0a(1) 조사 표에 올라온 동작 |

**등급**: A 그대로 둠 / B 몇 프레임만 고침 / C 다시 만듦. 1장의 보호 목록은 등급과 상관없이 고치지 않는다.

## 1. 손대지 않는 것 (보호 목록)

사용자가 "좋다"고 한 동작이다. 점검표에는 올리되 고치지 않는다. 사용자가 풀어 줄 때만 고친다.

| 캐릭터 | 보호 |
| --- | --- |
| 라이덴 | 도끼차기(내려찍기), 쓸기, 대시 공격, 공중 1~3타, 잔흔 |
| 백은우 | 공중 1~3타 |
| 에드워드 | 껍데기, 필살기 껍데기 뒤집어쓰기 |
| 오스카 | 걷기, 대시(월영), 벽 기동, 검영 밟기 |

재수정에서 사용자가 승인한 동작도 이 목록에 더한다.

## 2. 일곱 요소의 숫자 기준

| 요소 | 기준 |
| --- | --- |
| 1. 상체 비틀림 | 감기 마지막 프레임에서 치는 쪽 어깨가 엉덩이보다 4~8px 뒤에 있다. 타격 프레임에서는 4~6px 앞(2장) |
| 2. 무게중심 이동 | 감기 때 엉덩이가 뒷발 쪽으로 4~8px, 타격 때 앞발 쪽으로 8~16px 옮겨 간다. 엉덩이 높이도 2~6px 출렁인다 |
| 3. 어깨가 먼저 | 어깨가 손보다 1~2프레임 먼저 움직이기 시작한다 |
| 4. 팔과 무기는 늦게 | 팔꿈치 → 손 → 무기 끝 순서로, 하나가 1~2프레임씩 늦게 가장 빨라진다. 머리카락·옷자락·연검 끝은 2~4프레임 늦다 |
| 5. 타격 실루엣 | 뒷발 → 엉덩이 → 어깨 → 손(발·무기)이 거의 한 직선이다(동작연출지침서 2장). 단색으로 칠해도 무슨 공격인지 읽힌다 |
| 6. 반동 | 타격 다음 1~2프레임 동안 손·무기 끝이 4~10px 더 나갔다가 2~4px 되돌아온다 |
| 7. 자세 회복 | 처음엔 빠르고 끝으로 갈수록 느려지며 기본자세로 돌아온다. 회복 첫 프레임에 무게가 뒤로 빠진다 |

- **호**: 손·발·무기 끝은 호를 그린다. 두 키 사이가 직선으로 이어지면 중간 키를 넣어 휘게 한다.
- **간격**: 감기 끝은 `stop`으로 잠깐 멈추고, 스미어는 1틱, 회복은 점점 느리게. 빠르기는 프레임 수가 아니라 `dur`와 보간으로 조절한다.
- **프레임 수**: 위 요소를 다 담는 데 필요한 만큼만 쓴다. 요소가 없는 중간 프레임은 넣지 않는다.

## 3. 캐릭터별 몸의 언어

같은 기준이라도 캐릭터마다 몸을 쓰는 방식이 다르다. 네 명을 나란히 놓았을 때 실루엣과 박자만으로 누군지 알아봐야 한다.

| 캐릭터 | 몸의 언어 | 박자 |
| --- | --- | --- |
| 라이덴 (MMA) | 골반 회전으로 친다. 대기에서 앞뒤로 가볍게 튀며(주기 30~40틱), 치고 나면 손이 바로 얼굴 앞 가드로 돌아온다 | 감기 2~3프레임으로 짧게 끊어 치고, 반동도 짧다 |
| 백은우 (연검) | 멈추지 않는 흐름. 몸 전체가 S자, 팔은 크게 원을 그린다. 한 동작의 끝이 다음 동작의 시작이다. 머리·가운·연검은 늦게 따라오고 한 번 지나쳤다 돌아온다 | 프레임이 많고 dur가 고르게 짧다. 정지가 거의 없다 |
| 에드워드 (해머) | 무게. 해머 머리가 가장 늦게 따라오고, 친 뒤에는 몸이 해머에 끌려간다. 엉덩이 높이가 크게 출렁이고, 디딜 때마다 2px 내려앉는다 | 감기가 길다(`stop` 6~8틱). 회복이 느리다 |
| 오스카 (발도) | 정적과 순간. 굽은 노인 자세를 지키고, 몸 대신 손과 칼자루만 움직인다. 움직이기 직전 1~2프레임 완전히 멈춘다 | 칼 동작은 스미어 1프레임. 납도할 때 칼자루가 닿는 순간 1프레임 정지 |

동작연출지침서 9~13장의 캐릭터별 내용과 어긋나면 지침서가 우선이다.

## 4. 진행 방식 — 캐릭터 하나씩, 묶어서 검토

- **캐릭터 하나 = PR 하나**, 동작 하나 = 커밋 하나.
- 순서: 점검표 → C 등급 → B 등급.
- PR 설명에 동작마다 **번호를 붙여** 아래를 넣는다.
  - 전후 GIF(같은 위치, 실제 속도). 판정 상자 표시는 끈다.
  - 일곱 요소가 든 프레임 번호, 프레임 수와 그렇게 정한 이유 한 줄.
- 사용자는 번호로 답한다(예: "3 좋아, 5 감기 더 길게"). 좋다고 한 것은 `docs/motions/승인목록.md`에 적고 1장 보호 목록에 더한다.
- 그림을 바꾼 뒤 판정 상자를 겹쳐 본다. 그림과 판정이 8px 넘게 어긋나면 표에만 적는다(판정을 고칠지는 사용자가 정한다).
- 이펙트 시작점이 손·발 위치를 따른다면, 새 자세에 맞게 따라가는지 확인한다.
- 캐릭터 순서: 라이덴 → 백은우 → 에드워드 → 오스카 → 공통 동작 7개.

## 5. 확인

- 동작마다 실제 속도 GIF와 0.5배속 GIF.
- 손·발·무기 끝 경로를 점으로 찍은 그림(호인지, 간격이 변하는지).
- 단색 실루엣 띠(대기와 타격이 다른지).
- 네 캐릭터 같은 공격(예: 기본 1타)의 타격 프레임을 나란히 놓은 비교 PNG.
- simtest 결정론, 같은 시드 자동 대전 결과가 바꾸기 전과 같은지(그림만 바꿨으니 같아야 한다).
