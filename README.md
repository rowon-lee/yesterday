# YESTERDAY 스틱 액션

YESTERDAY 세계관의 2D 도트 액션 게임. 작업 규칙은 [CLAUDE.md](CLAUDE.md), 기획은 `docs/`.

- 배포: main에 머지되면 GitHub Actions가 빌드해서 GitHub Pages에 올린다. PR에서는 빌드와 simtest만 돌린다.
- `npm run build` — 타입 검사 + 빌드 (`dist/`)

## 확인 도구

| 명령 | 하는 일 | 결과 |
| --- | --- | --- |
| `npm run sheets` | `src/anim/motions.ts`의 모든 동작을 가로 띠(4배, 프레임 번호)로 출력. 12~14프레임 규칙 검사 | `out/sheets/<캐릭터>/<동작>.png`, 같은 이름 `.md`에 프레임별 표시 틱 표 |
| `npm run sheets -- --approve raiden/jab` | 위와 같고, 승인 요청용으로 `previews/`에 복사 | `previews/raiden/jab.png` |
| `npm run shot` | 장면을 PC·휴대폰 크기로 캡처. 오류·정수배·틱 속도·키 입력 확인 | `out/shots/<장면>-<화면>.png` |
| `npm run shot -- blank --tick 300 --view pc-1280x720` | 장면·멈출 틱·화면 크기 지정 | |
| `npm run shot -- "fight?p1=cpu" --tick 3000 --fast` | 주소 옵션을 붙인 장면, 멈출 틱까지 바로 돌려서 찍기 | |
| `npm run clip -- "fight?p1=cpu&seed=5" --from 130 --ticks 200 --name 이름` | 장면 한 토막을 움직이는 GIF로 (2배, 30fps). 동작 느낌 확인·PR 미리보기용 | `out/clips/이름.gif` |
| `npm run simtest` | CPU끼리 N판 대전. 예외, 규칙 범위(체력·기력·방어 내구도·위치), 경기 종료, `sim/`의 무작위·시간 값 사용, 같은 입력 재생·저장/복원 후 상태 해시 일치 확인. 히트·띄우기·낙법·크러시 등 집계 | 콘솔 |
| `npm run simtest -- --matches 50 --ticks 5400 --seed 7` | 판 수·판당 최대 틱·시작 시드 지정 | |
| `npm run compare` | 무대를 바꿨을 때: 고정 카메라 지점 세 곳(극장·다이너 거리, 시타델 광장, 비상계단 아파트)을 이전 버전(기본 origin/main)과 지금 버전으로 찍어 컬러·흑백으로 나란히 놓고, 벽·바닥·주인공 간판의 흑백 밝기를 잰다. `--base 커밋`, `--only theater`, `--new "옵션"`(지금 버전 주소에 붙임) | `out/compare/<지점>-color.png`, `-gray.png`, `stats.md` |

장면은 `src/scenes/index.ts`에 등록하고, 게임 주소 뒤 `?scene=이름`으로 열 수 있다.

## 대련 (연습: 1P 대 CPU)

배포 주소: https://rowon-lee.github.io/yesterday/

| 버튼 | 키 |
| --- | --- |
| 방향 (← → 뛰기, ↓ 방어, ↑+공격 띄우기, ↓+공격 쓸기·내려찍기) | 화살표 또는 WASD |
| 공격 | J |
| 점프 (공중에서 2단 점프, 맞고 있을 때 낙법) | K |
| 대시 (← 누르고 대시 = 뒤로) | L |
| 벽 기동: 공중에서 벽 쪽 대각선 위(↗·↖)로 붙기, 붙은 채 점프로 벽 점프, 붙은 채 공격으로 벽 박차기 공격, ↑+대시로 벽 쪽 달려 오르기, 벽꽝으로 건물 정면에 박히는 순간 점프로 벽 낙법. ↑ 없이 뛰거나 대시하면 구조물 앞을 지나간다 (맵 양 끝 벽은 ↑ 없이도 된다) | 방향 + J · K · L |
| 기술 A · 기술 B · 필살 | U · I · O |
| 판정 상자 켜고 끄기 | B |

주소 옵션: `?p2=idle` 상대가 가만히 섬 (연습), `?p1=cpu` CPU끼리 (구경), `?boxes=1` 판정 상자, `?seed=n` CPU 시드.

## 무대 보기

`?scene=stage`: 대련 무대 '시타델 1구역'만 띄운다. 카메라가 맵 끝에서 끝까지 오가고, ← →로 직접 움직일 수 있다. `?cam=900&camy=120`처럼 카메라 위치(가로, 세로)를 고정할 수도 있다. ↑↓로 세로도 움직인다. `?fg=0`은 앞겹을 끄고, `?plat=1`은 발판과 벽을 보인다(중층 노랑, 옥상 하늘색, 벽 기동용 벽 분홍, 맵 끝 벽 빨강). 대전 화면에서는 `?boxes=1`(또는 B 키)로 판정 상자와 함께 발판을 볼 수 있다. 대전에서 `?x=700`은 두 사람을 그 월드 x 양쪽에서 시작시키는 확인용 옵션이다.

- 배치 숫자: `src/data/stages/citadel.ts`, 배치 계산(건물·발판·물건·덩어리 격자): `src/stage/citadel.ts`
- 맵 3200×540px, 화면 480×270. 카메라가 두 사람을 가로·세로로 따라간다. 띄우기·공중 콤보 때는 떠오른 높이의 대부분만큼 스프링으로 부드럽게 올라가 위층과 하늘이 보인다(`src/scenes/fight.ts`의 `CAMERA_*`).
- 구간 5개 (월드 x): 해안 부두 0~400 → 극장·다이너 거리 400~1000 → 시타델 광장 1000~2200 → 비상계단 아파트 2200~2800 → 시타델 공원 2800~3200. 싸움은 광장 분수 양쪽(1480, 1720)에서 시작한다. 서쪽 끝은 컨테이너 더미, 동쪽 끝은 철책 벽.
- 축척 (아트 규칙): 캐릭터 키 52px, 문 약 70px, 1층 110px·위층 90px (2~5층 = 200~470px), 1960년대 자동차 120px, 가로등 110px.
- 시타델 본관(광장, 무너지지 않음): 1960년대 마천루의 아랫부분. 유리 커튼월(콘크리트 기둥·쇠 멀리언·층마다 스팬드럴, 불 켜진 사무실), 기둥이 늘어선 유리 로비, 계단참에서 솟은 유리 홀, 유리 정문과 캐노피, 정문 양옆 콘크리트 기둥(빛 홈, 중간 캔틸레버 테라스·꼭대기 항공 경고등, 발치 투광등), 빛나는 CITADEL 간판, 옥상 서치라이트, 분수, 히어로 동상, 문기둥과 등롱, 검문소. 커튼월 숫자는 `src/data/stages/citadel.ts`의 `plaza.keep`.
- 높이 세 층과 한 방향 발판 (`src/sim/platforms.ts`): 지상, 중층(차양 76·극장 차양 92·계단참 88·비상계단 114~384·등대 발코니 92·컨테이너 더미 112), 옥상(지붕·기둥탑 테라스 200·꼭대기 296·등대 둘레 196·급수탑 344). 위에서 내려올 때만 서고, ↓+점프로 내려오고, 끝을 넘으면 떨어진다. 부서지는 건물에 붙은 발판은 그 자리가 무너지면 사라진다. 점프 한 번은 약 95px, 2단 점프까지 약 160px 오른다.
- 구조물 (기획서 '벽 기동과 구조물', 숫자는 `src/stage/citadel.ts`의 `SURFACES`·`WALLS`): 윗면은 위 발판, 옆면은 벽 기동용 벽(길은 막지 않는다). 맵 끝 벽(컨테이너 더미 앞면 112, 공원 철책 150), 등대, 극장 전구 차양, 비상계단, 정문 기둥탑, 급수탑. 상태에 따라 생기는 것: 등대 밑동(120), 뒤집힌 노면전차(60), 쓰러진 시타델 간판(50), 건물이 무너진 자리의 잔해 더미(43~60). 서쪽 컨테이너 더미 위에도 설 수 있다(그 높이 위에서는 더미 위까지 가고, ↓+점프로 뚫리지 않는다).
- 큰 물건 4개 (노면전차·식료품점 지붕 급수탑·부두 등대·시타델 정면 간판): 평타·기술로는 망가짐까지만, 필살기가 닿거나 '벽 쪽으로 날림' 기술에 맞아 날아온 상대가 부딪히면 크게 무너진다(sim `src/sim/props.ts`, 그림 `src/render/gl/bigprops.ts`). 전차는 도시 시계(필살 컷인 동안 멈춤)로 다닌다. 간판이 떨어지면 광장 전기가 나간다.
  `?scene=stage&big=0`(큰 물건만 틱 0에 무너뜨림, 숫자가 무너지는 틱)·`big=d`(망가짐), `?tram=560`(전차가 탈선한 자리), `?broke=틱`(`props=2`의 부서진 틱).
- 배경 6겹 (괄호는 카메라 대비 움직이는 비율): 하늘과 바다·등대 불빛(0.03) → 1구역 마천루와 공장 굴뚝(0.12) → 시타델 탑 윗부분: 층층이 들어간 마천루 몸통·빛나는 유리 왕관·안테나와 경고등·서치라이트(0.3) → 중간 건물(0.6) → 싸우는 거리(1) → 앞겹: 가로등 기둥·전선·깃대와 깃발(1.5, 화면 가장자리에서만 보이는 어두운 실루엣).
- 움직이는 도시 (`src/render/gl/life.ts`): 1960년대 유선형 노면전차가 25초마다 부두와 극장 거리를 건물 앞 차선으로 지나가고(전조등 빛줄기, 가공선 불꽃. 자리는 sim의 도시 시계로 정해지고, 무너진 뒤에는 다니지 않는다), 서치라이트(본관 옥상·탑 왕관·등대)가 하늘을 쓸고, 항공 경고등이 깜빡이고, 공장 굴뚝 매연이 오르고, 분수가 솟고, 옥상 전광판 글씨가 흐르고, 멀리 행인이 싸움 반대쪽으로 도망간다(광장·공원·골목 틈으로 보인다).
- 부서지는 물건 41개 (1960년대 세단 5, 코브라 헤드 가로등 14, 쇼윈도 6, 신문 가판대 2, 소화전 4, 네온 간판·전광판 10): 위치·판정은 `src/stage/citadel.ts`, 상태(내구도·단계·부서진 틱)는 sim(`src/sim/props.ts`), 그림은 `src/render/gl/props.ts`(단계별 텍스처는 `proptex.ts`, 불길·연기·불꽃·물기둥은 `fx.ts`). 쇼윈도·네온 간판은 붙어 있는 건물 덩어리가 무너지면 같이 사라진다. 가로등·네온은 망가지면 깜빡이고, 부서지면 빛도 꺼진다(부서진 상태는 sim, 빛은 렌더). 차는 망가지면 앞에서 불이 나고 부서지면 타 버린 차체가 불길·연기를 내다 그을음만 남는다. 가로등은 휘었다가 쓰러지고, 소화전은 물기둥과 물웅덩이(바닥 반사가 세다)를 남긴다.
  `?scene=stage&props=1`(망가짐)·`props=2`(파괴), 또는 1~3 키로 세 단계를 볼 수 있다.
- 건물 파괴: 길가 건물 8채의 정면을 16×16 덩어리 1,626개로 나눠 덩어리마다 내구도(금 → 구멍 → 뚫림, 무너지면 사라짐). 시타델 본관·콘크리트 기둥은 아직 부서지지 않는다(본관은 '시타델 붕괴'에서). 규칙 숫자는 `src/data/stages/citadel.ts`의 `city`, 상태·붕괴·벽꽝은 sim(`src/sim/city.ts`), 그림은 `src/render/gl/buildings.ts`: 정면 텍스처에서 바뀐 덩어리만 고쳐 그리고, 뚫린 자리 뒤로 실내 판(`interior.ts`: 방·가게·다이너·객석)이 깊이를 두고 보인다. 무너진 칸은 정면·실내·몸통·처마·차양·비상계단이 칸 단위로 사라지고(셰이더가 칸 번호로 지운다) 앞에 잔해 더미가 쌓인다(다 쌓이면 발판·벽, 한동안 불타고 잉걸불이 남는다). 떨어지는 조각·먼지 구름은 `src/render/debris.ts`(렌더 전용).
  `?scene=stage&ruin=1`은 단계별로 몇 군데를 부순 모습, `?scene=stage&match=1`은 시드 1로 CPU끼리 한 경기를 끝까지 돌린 뒤의 거리(파괴는 라운드가 넘어가도 남는다).

## 2.5D 렌더 (기준: The Last Night)

도트 그림을 3D 공간에 놓고 실제 광원으로 비춘다. 대련(`fight`)과 무대 보기(`stage`)는 이 화면으로 그린다. WebGL2가 없는 브라우저에는 안내 글을 띄운다. 모션 뷰어처럼 무대가 없는 장면은 2D 캔버스에 바로 그린다.

- 렌더 전용이다. `src/sim`은 three.js를 모른다. three.js(WebGL2)가 런타임 의존성 하나다. 코드는 `src/render/gl/`.
- 카메라 (`core.ts`, `view.ts`): 싸우는 면에서 3,000px 떨어진 원근 카메라(시야각 약 5°)라 싸우는 면에서 월드 1px = 화면 1px이고 거의 평면처럼 보인다. 482×272(둘레 1px 여유) HDR 화면에 그리고, 카메라는 정수 px로만 움직이고 남는 소수점만큼 마지막 확대 단계에서 화면을 민다. 먼 겹은 겹 속도에 맞는 깊이에 놓아 2D와 같은 시차로 움직인다(`backdrops.ts`).
- 깊이 (카메라 쪽이 +): 건물 몸통 -180 → 실내 판 -60 → 건물 정면 -40 → 보도 → 주차된 차 -22~-8 → 전차 -4 → 싸우는 면 0 → 앞겹 +1,000. 광장은 본관 정면이 -170이고 그 앞에 계단(뒤로 올라감)과 분수가 있다. 올라서는 곳(처마·차양·극장 차양·비상계단 발판·계단참·테라스·등대 둘레)은 싸우는 면까지 튀어나와 그 위에 선 캐릭터와 깊이가 맞고, 올라서지 못하는 덩어리는 싸우는 면보다 뒤에 있어 캐릭터가 그 앞을 지나간다.
- 구간 (`buildings.ts` 길가 건물 두 구간, `plaza.ts` 광장과 본관, `edges.ts` 부두와 공원, `street.ts` 구간마다 다른 젖은 바닥·전차 가공선·길가 소품·앞겹): 건물은 상자, 텍스처는 오프스크린 Canvas 2D에 그린 도트(`tex.ts`: 건물·창마다 씨앗이 달라 되풀이하지 않음, 얼룩·빗물 자국·금·찢긴 포스터·바랜 광고, 창은 일부만 켜짐·커튼·블라인드·사람 그림자·TV 깜빡임). 텍스처 한 칸이 화면 1px이 되게 깊이만큼 줄여 그린다. 작은 장식은 한 덩어리로 묶어 그린다(`kit.ts`).
- 조명 (`lights.ts`, `shaders.ts`): 차가운 남색 반구 환경광에서 시작해 광원 풀로 비춘다. 간판·가로등·창·쇼윈도·골목 전구·TV·투광등·불길·이펙트가 빛 후보를 내면 화면에 가장 크게 닿는 12개(낮은 품질 6개)만 셰이더에 싣는다. 간판 위계: 극장 거리 PALACE, 아파트 RADIO, 광장 CITADEL만 가장 밝고, 나머지는 어둡거나(DINER·GROCER) 깜빡이거나(HOTEL 세로 간판·LAUNDRY) 꺼짐. 부서지면(sim) 빛도 꺼진다.
- 젖은 바닥 (`post.ts`): 화면 공간 반사. 카메라가 거의 수평이라 바닥은 화면 아래 30줄 남짓이므로, 바닥선 위 장면을 늘여 뒤집어 비추고(네온·창이 길게 비침) 줄마다 물결로 흔든다. 웅덩이는 더 세게, 공원 자갈길은 약하게.
- 공기와 비 (`rain.ts`, `steam.ts`, `world.ts`): 겹 사이 안개 판, 바닥 안개, 가로등·투광등·서치라이트·전조등 빛줄기, 하수구 증기, 무채색 빗줄기 세 겹(빛 안에서만 그 빛 색), 바닥·발판 물방울.
- 캐릭터 (`actors.ts`): 미리 그린 시트를 싸우는 면의 판으로 세우고, 가장 센 가까운 광원 쪽 테두리를 그 빛 색으로. 먼지·잔상·무너지는 조각·Sprite Fusion 이펙트는 2D 그림을 싸우는 면 바로 뒤·앞의 평면 층에 그린다(무너지는 조각은 밤빛을 입힌 정면 그림에서 잘라 온다).
- 후처리 (`post.ts`): 빛 번짐(밝은 곳만 약하게) → 깊이 외곽선 1px(평면에는 긋지 않음) → COLORS와 남색·주황·분홍·청록 계단을 합친 팔레트로 줄이고 4×4 디더링. HUD는 위에 겹친 같은 해상도 2D 캔버스.
- 휴대폰 60프레임: 틱이 넘어간 프레임만 그린다(120Hz 화면에서 두 번 그리지 않음). 2초 평균 그리기 시간이 12ms를 넘거나 프레임마다 틱이 평균 1.3개를 넘으면(60프레임을 못 따라감) 낮은 품질로 내린다: 광원 6개, 빗줄기 절반, 빛 번짐 끔.

## 이펙트

Sprite Fusion 픽셀 아트 VFX (MIT, https://www.spritefusion.com/pixel-art-vfx) 파일을 `src/vfx/`에 두고 쓴다.
`src/render/vfx.ts`가 우리 화면에 맞춘다 (좌표 2단위 = 1px, 반투명 → 4×4 디더링, 색 → 제한 팔레트).
전투 이벤트와의 연결은 `src/render/fightvfx.ts`.
