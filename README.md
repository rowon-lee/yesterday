# YESTERDAY 스틱 액션

YESTERDAY 세계관의 2D 도트 액션 게임. 작업 규칙은 [CLAUDE.md](CLAUDE.md), 기획은 `docs/`.

- 배포: main에 머지되면 GitHub Actions가 빌드해서 GitHub Pages에 올린다. PR에서는 빌드와 simtest만 돌린다.
- `npm run build` — 타입 검사 + 빌드 (`dist/`)

## 확인 도구

| 명령 | 하는 일 | 결과 |
| --- | --- | --- |
| `npm run sheets` | `src/anim/motions.ts`의 모든 동작을 가로 띠(4배, 프레임 번호)로 출력. 12~14프레임 규칙 검사 | `out/sheets/<캐릭터>/<동작>.png`, 같은 이름 `.md`에 프레임별 표시 틱 표 |
| `npm run sheets -- --approve raiden/jab` | 위와 같고, 승인 요청용으로 `previews/`에 복사 | `previews/raiden/jab.png` |
| `npm run shot` | 장면을 PC·휴대폰 크기로 캡처. 오류·정수배·틱 속도·키 입력 확인 | `out/shots/<장면>-<화면>.png` |
| `npm run shot -- blank --tick 300 --view pc-1280x720` | 장면·멈출 틱·화면 크기 지정 | |
| `npm run shot -- "fight?p1=cpu" --tick 3000 --fast` | 주소 옵션을 붙인 장면, 멈출 틱까지 바로 돌려서 찍기 | |
| `npm run clip -- "fight?p1=cpu&seed=5" --from 130 --ticks 200 --name 이름` | 장면 한 토막을 움직이는 GIF로 (2배, 30fps). 동작 느낌 확인·PR 미리보기용 | `out/clips/이름.gif` |
| `npm run simtest` | CPU끼리 N판 대전. 예외, 규칙 범위(체력·기력·방어 내구도·위치), 경기 종료, `sim/`의 무작위·시간 값 사용, 같은 입력 재생·저장/복원 후 상태 해시 일치 확인. 히트·띄우기·낙법·크러시 등 집계 | 콘솔 |
| `npm run simtest -- --matches 50 --ticks 5400 --seed 7` | 판 수·판당 최대 틱·시작 시드 지정 | |

장면은 `src/scenes/index.ts`에 등록하고, 게임 주소 뒤 `?scene=이름`으로 열 수 있다.

## 대련 (연습: 1P 대 CPU)

배포 주소: https://rowon-lee.github.io/yesterday/

| 버튼 | 키 |
| --- | --- |
| 방향 (← → 뛰기, ↓ 방어, ↑+공격 띄우기, ↓+공격 쓸기·내려찍기) | 화살표 또는 WASD |
| 공격 | J |
| 점프 (공중에서 2단 점프, 맞고 있을 때 낙법) | K |
| 대시 (← 누르고 대시 = 뒤로) | L |
| 기술 A · 기술 B · 필살 | U · I · O |
| 판정 상자 켜고 끄기 | B |

주소 옵션: `?p2=idle` 상대가 가만히 섬 (연습), `?p1=cpu` CPU끼리 (구경), `?boxes=1` 판정 상자, `?seed=n` CPU 시드.

## 무대 보기

`?scene=stage`: 대련 무대 '시타델 1구역'만 띄운다. 카메라가 맵 끝에서 끝까지 오가고, ← →로 직접 움직일 수 있다. `?cam=900&camy=120`처럼 카메라 위치(가로, 세로)를 고정할 수도 있다. ↑↓로 세로도 움직인다. `?fg=0`은 앞겹을 끄고, `?plat=1`은 발판을 보인다(중층 노랑, 옥상 하늘색). 대전 화면에서는 `?boxes=1`(또는 B 키)로 판정 상자와 함께 발판을 볼 수 있다.

- 배치 숫자: `src/data/stages/citadel.ts`, 배치 계산(건물·발판·물건·덩어리 격자): `src/stage/citadel.ts`
- 맵 3200×540px, 화면 480×270. 카메라가 두 사람을 가로·세로로 따라간다. 띄우기·공중 콤보 때는 떠오른 높이의 대부분만큼 스프링으로 부드럽게 올라가 위층과 하늘이 보인다(`src/scenes/fight.ts`의 `CAMERA_*`).
- 구간 5개 (월드 x): 해안 부두 0~400 → 극장·다이너 거리 400~1000 → 시타델 광장 1000~2200 → 비상계단 아파트 2200~2800 → 시타델 공원 2800~3200. 싸움은 광장 분수 양쪽(1480, 1720)에서 시작한다. 서쪽 끝은 컨테이너 더미, 동쪽 끝은 철책 벽.
- 시타델 본관(광장, 무너지지 않음): 정문 계단과 계단참, 정문 양옆 기둥탑(중간 테라스·꼭대기), 정면 대형 간판, 지붕 서치라이트, 분수, 히어로 동상.
- 길가 건물 3~6층 (1층 80px, 위층 56px → 192~360px): 상가·극장·다이너·비상계단 아파트. 바닥에 서 있으면 위가 화면 밖으로 잘린다.
- 높이 세 층과 한 방향 발판 (`src/sim/platforms.ts`): 지상, 중층(차양 76·극장 차양 92·계단참 88·비상계단 84~308·등대 발코니 92), 옥상(지붕·기둥탑 테라스 200·꼭대기 296·등대 둘레 196). 위에서 내려올 때만 서고, ↓+점프로 내려오고, 끝을 넘으면 떨어진다. 부서지는 건물에 붙은 발판은 그 자리가 무너지면 사라진다. 점프 한 번은 약 95px, 2단 점프까지 약 160px 오른다.
- 배경 6겹 (괄호는 카메라 대비 움직이는 비율): 하늘과 바다·등대 불빛(0.03) → 1구역 마천루(0.12) → 시타델 상층부와 서치라이트(0.3) → 중간 건물(0.6) → 싸우는 거리(1) → 앞겹: 가로등 기둥·전선·깃대(1.5, 캐릭터 앞, 캐릭터와 겹치면 디더링으로 비침). 먼 겹일수록 매연 색 디더링으로 덮는다(흐림 대신).
- 움직이는 도시 (렌더 전용, `src/render/stage/life.ts`): 노면전차가 25초마다 부두와 극장 거리를 건물 앞 차선으로 지나가고, 서치라이트(본관 지붕·상층부·등대)가 하늘을 쓸고, 분수가 솟고, 옥상 전광판 글씨가 흐르고, 멀리 행인이 싸움 반대쪽으로 도망간다(광장·공원·골목 틈으로 보인다).
- 부서지는 물건 31개 (자동차 5, 가스등 14, 쇼윈도 6, 신문 가판대 2, 소화전 4): 위치·판정은 `src/stage/citadel.ts`, 상태(내구도·단계·부서진 틱)는 sim(`src/sim/props.ts`), 그림은 `src/render/stage/props.ts`.
  `?scene=stage&props=1`(망가짐)·`props=2`(파괴), 또는 1~3 키로 세 단계를 볼 수 있다.
- 건물 파괴: 길가 건물 8채의 정면을 16×16 덩어리 1277개로 나눠 덩어리마다 내구도(금 → 구멍 → 뚫림, 무너지면 사라짐). 시타델 본관·기둥탑·등대는 부서지지 않는다. 실내는 건물 종류마다 다르다. 규칙 숫자는 `src/data/stages/citadel.ts`의 `city`, 상태·붕괴·벽꽝은 sim(`src/sim/city.ts`), 그림(실내·잔해 더미)은 `src/render/stage/city.ts`, 떨어지는 조각·먼지 구름은 `src/render/debris.ts`(렌더 전용).
  `?scene=stage&ruin=1`은 단계별로 몇 군데를 부순 모습, `?scene=stage&match=1`은 시드 1로 CPU끼리 한 경기를 끝까지 돌린 뒤의 거리(파괴는 라운드가 넘어가도 남는다).
- 그리기: `src/render/stage/` (겹 미리 그리기 `layers.ts`, 매 틱 덧그리기 `index.ts`, 서치라이트는 픽셀 버퍼 `pixels.ts`)

## 이펙트

Sprite Fusion 픽셀 아트 VFX (MIT, https://www.spritefusion.com/pixel-art-vfx) 파일을 `src/vfx/`에 두고 쓴다.
`src/render/vfx.ts`가 우리 화면에 맞춘다 (좌표 2단위 = 1px, 반투명 → 4×4 디더링, 색 → 제한 팔레트).
전투 이벤트와의 연결은 `src/render/fightvfx.ts`.

| 쓰임새 | 이펙트 |
| --- | --- |
| 타격 / 막힘 | Impact (뜨거운 색 / 차가운 색) |
| 발차기·쓸기·내려찍기 궤적 | Slash |
| 대시·공중 대시 | Dash & Blink |
| 기력 3칸이 찬 동안 | Power Up (1P 금빛, 2P 하늘빛) |
| 필살 적중·가드 크러시·KO | Explosion |

## 모션 뷰어

배포 주소 뒤에 `?scene=viewer`: https://rowon-lee.github.io/yesterday/?scene=viewer

화면 아래 버튼으로 동작 선택, 재생/정지, 한 프레임씩, 1·0.5·0.25배속, 판정 상자, 1P/2P 색, 좌우를 바꾼다.
키보드: ↑↓ 동작, ←→ 한 프레임, Space 재생/정지, S 속도, H 판정, C 색, F 좌우.
